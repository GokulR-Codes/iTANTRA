# experiments/

One dated markdown file per experiment (§41) — e.g.
`2026-09-15-energy-vad-threshold-sweep.md`. Each file records: hypothesis,
method, raw result location, and conclusion, even (especially) for
experiments that failed or were inconclusive. This is a lab notebook, not a
changelog — DECISIONS.md records what the project committed to; this
directory records what was tried to get there, including dead ends, so the
same dead end doesn't get re-walked by a future session.

**Status: empty.** No experiments have been run yet — Gate 1 is scaffolding
and interface work, not empirical tuning.
